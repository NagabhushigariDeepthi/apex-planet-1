# Bank Customer Churn Analysis

## TASK 1 – Data Immersion & Wrangling

### 📌 Project Overview

This project focuses on analyzing a real-world banking dataset to understand customer behavior and prepare the data for further analytical processes such as Exploratory Data Analysis (EDA), dashboard development, and business intelligence reporting.

The primary objective of Task 1 was to clean, transform, and preprocess the dataset to ensure data quality and consistency.

---

## 📊 Dataset Information

Dataset Used: `Churn_Modelling.csv`

The dataset contains customer banking information such as:

* Credit Score
* Geography
* Gender
* Age
* Account Balance
* Estimated Salary
* Customer Activity
* Churn Status
